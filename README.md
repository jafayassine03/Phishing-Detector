PhishGuard

PhishGuard is a simple cyber security awareness web project that helps users practice detecting phishing emails. The website presents different email examples and asks the user to decide whether each message is safe or a phishing attempt.

The project was built using HTML, CSS, and JavaScript with a clean dark-themed interface and interactive scoring system.

Features
Interactive phishing detection challenge
Realistic email examples
Instant feedback after each answer
Score tracking system
Responsive design for mobile and desktop
Beginner-friendly project structure
Technologies Used
HTML5
CSS3
JavaScript
How It Works
The website displays an email example.
The user selects either:
Safe
Phishing
The system checks the answer instantly.
The user receives feedback and explanation.
The score updates after every round.
Project Goal

The goal of this project is to improve cyber security awareness by teaching users how to identify common phishing techniques such as:

Fake sender domains
Urgent warning messages
Suspicious account verification requests
Payment scams
Social engineering tactics
